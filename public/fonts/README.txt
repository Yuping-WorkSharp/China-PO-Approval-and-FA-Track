Optional: make the tracker use the same Barlow font as the Claude version.

1. Go to https://fonts.google.com/specimen/Barlow and click "Get font", then "Download all". Unzip it.
2. Go to https://fonts.google.com/specimen/Barlow+Condensed and do the same.
3. Copy these 7 files into this folder (public/fonts):
   Barlow-Regular.ttf
   Barlow-Medium.ttf
   Barlow-SemiBold.ttf
   Barlow-Bold.ttf
   BarlowCondensed-Medium.ttf
   BarlowCondensed-SemiBold.ttf
   BarlowCondensed-Bold.ttf
4. Commit and push. Render redeploys automatically.

Barlow is free to use under the SIL Open Font License.
Without these files the tracker still works and uses standard system fonts.
